# RadarSantos

Aplicativo Android pessoal com mapa, GPS, distância e alertas de pontos de
fiscalização em Santos/SP.

## Baixar o APK

Quando a ação "Gerar APK Android" terminar, abra a aba Releases deste
repositório e baixe o arquivo app-debug.apk mais recente para instalar no
Android.

## Código do projeto

Baixe RadarSantos.zip, extraia a pasta e siga o README que está dentro dela.

Os dados de fiscalização são de referência e devem ser conferidos na CET-Santos
antes de dirigir.
